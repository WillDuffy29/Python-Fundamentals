# Python-Fundamentals
A collection of small Python programs created to practice core programming concepts as a beginner. These exercises focus on user input, arithmetic operations, conditional logic, and basic problem-solving.

INCLUDED PROGRAMS

1. Pythagoras Calculator
Calculates the hypotenuse of a right-angled triangle using user-provided side lengths.

2. Quadratic Formula Calculator
Solves quadratic equations using the standard formula.  

3. Coin Flip Demo
Simulates a coin flip using random numbers.  

4. Cyclone Exercise
Determines whether a user can ride a roller coaster based on height and credits.

5. FizzBuzz Exercise
Considers the numbers up to 100 which are multiples of 3, 5 or both.

6. Sum of Squares
A program which returns the sum of all the squares leading up to, and including, a number provided by user input. 

7. Lottery Game
This short game prints a selection of 'your numbers' and compares them to a selection of 'winning numbers', all randomly generated. 

8. DNA Listing Exercise
This exercise searched through a list to confirm the presence, or absence, of certain terms.

9. The Oscars Exercise
Utilises, manipulates and sorts lists.

10. Snake Eyes Game
Roll two die until you land on 'Snake Eyes'. Utilises 'while' loops.

11. Listing Methods
My notes on lists: how to manipulate, structure and print them.

12. Rock, Paper Scissors (Classic)
A classic game of rock, paper scissors!

HOW TO RUN

- Install Python onto your system
- Download the desired file and run inside your terminal
- Follow the on-screen prompts

CONCEPTS PRACTICED

- Variables and data types
- User input handling
- Arithmetic operations
- Conditional statements (if, elif, else)
- Using Python standard libraries (random)
- Program flow and simple logic
